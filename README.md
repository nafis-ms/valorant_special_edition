Project Overview

This repository contains a university project developed for the Graphics and Animation course. The project is created strictly for academic purposes.

The project is inspired by the FPS game Valorant. The goal is to recreate the core experience of a tactical first-person shooter while implementing the game using the graphics and animation concepts learned throughout the course.

Instead of online multiplayer, this project uses AI-controlled bots as opponents. To keep the implementation focused on graphics, animation, and gameplay fundamentals, the original character abilities have been excluded.

Key Features

* First-person shooter (FPS) gameplay
* AI-controlled enemy bots
* Shooting and weapon mechanics
* Player movement and camera control
* 3D environment and map design
* Character and weapon animations
* Collision detection
* Basic enemy AI
* No online multiplayer
* No character abilities

The project is inspired by Valorant but is not intended to be a commercial recreation or replacement of the original game. It is developed solely as an educational project to demonstrate concepts related to computer graphics, animation, and interactive game development.
